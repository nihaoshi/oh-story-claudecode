# 人物塑造深度技巧

> 来源：《人物塑造：让角色活过来》+ 《构思与大纲》+ 《七种类型风格写法详解》

---

## 一、角色亮相三秒法则

角色第一次出场给三个瞬间：**一个动作 + 一个眼神 + 一个说话方式**。

读者第一次见面不需要知道TA的过去，只需要感觉到TA是什么人。

**示例**：
```
❌ 他叫李明，是一个性格内向的中年人，平时不爱说话，但做事很认真。
✅ 李明把烟掐灭，朝窗外看了一眼。"行，我知道了。"说完就走了。
```

## 二、反应链理论：性格 = 反应方式

性格不是标签（"倔强""温柔"），而是人物遇事后的**惯性反应**。

写好四类关键场景的反应，性格就立住：

| 场景 | 检测什么 | 示例 |
|------|---------|------|
| 危险 | 是冲上去还是退缩？ | 冲上去=勇敢，退缩=谨慎，先观察=理智 |
| 争吵 | 是硬刚还是回避？ | 硬刚=直率，回避=隐忍，讲道理=理性 |
| 诱惑 | 是坚守还是动摇？ | 坚守=原则，动摇=人性，先犹豫后拒绝=真实 |
| 背叛 | 是报复还是原谅？ | 报复=有仇必报，原谅=宽容，表面原谅内心记仇=复杂 |

给每个主要角色写一段**"四场景反应"**，这就是TA的性格DNA。

## 三、弱点三件套

每个主要角色必须有：

| 弱点类型 | 描述 | 示例 |
|---------|------|------|
| 情绪弱点 | 怕什么/无法面对什么 | 怕身边人受伤、无法面对过去 |
| 智力盲区 | 看不懂什么/在哪方面迟钝 | 看不懂情感暗示、过于自信 |
| 现实限制 | 有什么把柄/短板 | 身上带着不能暴露的证据、被威胁 |

**弱点驱动剧情公式**：
弱点暴露 → 被对手利用 → 陷入困境 → 被迫选择 → 付出代价 → 成长或沉沦

## 四、人物塑造五步法

### 第一步：身份锚定

年龄 / 地域 / 阶层 / 职业 / 时代 → **身份决定视角和语言**

### 第二步：性格立体

- 2个优点 + 2个缺点 + 1个矛盾特质
- 口诀：好人的缺点让他真实，坏人的优点让他可怕

### 第三步：灵魂内核

回答三个问题：
- TA**最想要**什么？
- TA**最怕**什么？
- TA**绝不能失去**什么？

### 第四步：行为逻辑

一言一行完全符合性格。检验方法：**换一个人是否也会做同样选择？** 如果会，说明这个角色没有独特性。

### 第五步：成长弧光

经历磨难后性格蜕变 / 精神觉醒。真正的成长是：**"同样的事，做出了不同的选择"**

## 五、主角三要素（爆款逻辑）

| 要素 | 要求 | 反例→正例 |
|------|------|----------|
| 欲望（目标） | 必须明确且具体 | ❌ 追求强大 → ✅ 3年内成为金丹修士救出母亲 |
| 缺陷（弱点） | 必须有成长空间 | ❌ 完美无缺 → ✅ 过于自信导致判断失误 |
| 底牌（能力） | 必须有限制 | ❌ 无限金手指 → ✅ 有代价的特殊能力 |

## 六、对话写作：四点设定法

给每个角色定四个维度：

```
【{角色名} 对话四点】
1. 爱用的口头禅：[XXX]
2. 说话长度：[一句话/一小段/长篇大论]
3. 表达方式：[直说/暗示/反问/沉默]
4. 讨厌用的词：[绝对不会说的表达方式]
```

**对话五层境界**（从低到高）：
1. 传递信息
2. 展现性格
3. 推动冲突
4. 潜台词（说的和想的不一样）
5. 留白（最想说的话没说出口）

**对话去水原则**：每句对话至少承担一个功能（推动剧情/暴露性格/制造冲突/埋伏笔）

**遮名测试**：遮住角色名字，看能不能分辨谁在说话。能分辨 = 对话写得好。

## 七、反派塑造

### 工具人反派四大症状

目标模糊 / 性格单薄 / 行为矛盾 / 毫无成长

### 让反派活过来的五法

1. **给他真实信仰** — 最可怕的反派是真心觉得自己是对的
2. **挖掘人性切面** — 情感锚点 + 道德挣扎
3. **用前史构建逻辑** — 100字反派前传
4. **设计反派专属高光时刻** — 反派也有精彩的瞬间
5. **建立动态人物弧光** — 反派也会变化和成长

### 反派三句检测法

你的反派能回答这三个问题吗？
- "我做这件事的原因是..."
- "我不能容忍的是..."
- "我害怕失去的是..."

### 读者最买账的三种反派

1. 悲情哲学家（38%）— 有自己的道理，让人恨不起来
2. 优雅疯批美学（29%）— 疯狂但有魅力
3. 亦敌亦友同行者（23%）— 和主角相似却走上不同道路

## 八、配角设计

### 三类必须配角

| 类型 | 功能 | 示例 |
|------|------|------|
| 助攻型 | 帮主角/给信息/推关系 | 忠诚的伙伴、提供线索的路人 |
| 阻碍型 | 制造冲突/逼主角成长 | 嫉妒的同门、严格的师父 |
| 镜像型 | 和主角相似却选择不同，反衬主题 | 同样天赋但走上歧途的人 |

每个配角至少有一个**"不可替代的功能"**。如果删掉这个配角故事不受影响，说明他可以删。

### 人物关系网搭建法

```
先定主角
  → 给主角配一个对手（对立）
  → 给主角配一个镜子（镜像）
  → 给主角配一个羁绊（情感）
  → 让配角之间也有关系（不要所有关系都围着主角转）
```

## 九、成长可量化三节点

| 节点 | 表现 | 示例 |
|------|------|------|
| 情绪节点 | 忍不住冲动，付出代价 | 被激怒后出手，结果中了圈套 |
| 行为节点 | 憋住了但难受 | 明明想打人，忍住了，但手在发抖 |
| 价值观节点 | 遇更大刺激也稳定 | 即使最亲的人被威胁，也能冷静应对 |

核心：**真正的成长是"同样的事，做出了不同的选择"**

## 十、七种类型的人设要点

| 类型 | 人设重点 |
|------|---------|
| 玄幻/仙侠 | 境界+功法+血脉+势力归属，升级路径清晰 |
| 悬疑 | 每个角色都有秘密，知道什么/不知道什么是关键 |
| 言情 | 情感需求+情感障碍+感情弧光 |
| 科幻 | 所属阵营+技术能力+对科技的态度 |
| 现实主义 | 阶层+职业+时代烙印+人性灰度 |
| 历史 | 朝代身份+与真实人物的关系+时代局限 |
| 恐怖 | 恐惧来源+心理弱点+与超自然的关系 |
