# 情节设计方法论

> 来源：《情节设计：冲突、悬念、节奏与高潮》+ 《构思与大纲：从灵感到完整蓝图》

## 一、黄金开篇：前三章定生死

### 三章任务

| 章节 | 必须完成 | 禁忌 |
|------|---------|------|
| 第1章 | 抛出冲突+痛点（立刻出矛盾） | ❌ 大段环境描写、人物介绍清单、哲理开头、设定说明 |
| 第2章 | 给到转机/金手指（给希望，埋期待） | ❌ 继续铺垫没有进展 |
| 第3章 | 立短期目标（拉开主线，留悬念钩子） | ❌ 信息量过大，读者消化不了 |

### 三种经典开篇模式

| 模式 | 做法 | 适用类型 |
|------|------|---------|
| 冲突切入法 | 直接进入矛盾场景 | 所有类型（最推荐） |
| 悬念切入法 | 抛出一个谜题/异常 | 悬疑/科幻 |
| 反差切入法 | 展示反常的场景或角色状态 | 都市/言情 |

## 二、冲突制造

### 冲突公式

```
想要 → 得不到 → 有人拦 → 只能拼 → 付出代价
```

### 冲突四大来源

| 来源 | 描述 | 示例 |
|------|------|------|
| 人际冲突 | 人与人之间的矛盾 | 师徒反目、情敌对立 |
| 利益冲突 | 资源/地位/机会的争夺 | 宗门内斗、职场竞争 |
| 环境冲突 | 人与环境的对抗 | 天灾、末日、制度压迫 |
| 内心冲突 | 人与自己的矛盾 | 道德两难、恐惧与勇气 |

### 冲突叠加法

最有力的冲突是多层叠加：
```
外层冲突（打BOSS）+ 中层冲突（门派内斗）+ 内层冲突（自我怀疑）
```

### 冲突升级节奏

```
小冲突（1-3章）→ 解决
  ↓
中冲突（5-10章）→ 解决
  ↓
大冲突（一个卷）→ 解决
  ↓
终极冲突
```

**原则**：每个冲突解决后，下一个冲突必须**更难、更紧、代价更大**

## 三、悬念与钩子

### 四种经典钩子

1. **突然出现的人** — "门外站着一个人"
2. **突然反转的真相** — "但他不知道的是..."
3. **突然到来的危机** — "就在这时，远处传来一声爆炸"
4. **一句让人震惊的话** — "她只说了三个字：'不是我。'"

### 钩子频率

- **章中钩子**：每500-800字一个小悬念
- **章尾钩子**：每章结尾必须留一个钩子

### 信息差制造悬念

| 信息差类型 | 效果 | 用法 |
|-----------|------|------|
| 读者知道，角色不知道 | 焦虑 | 读者看到危险逼近主角 |
| 角色知道，读者不知道 | 好奇 | 角色突然做出反常行为 |
| 谁都不知道 | 震惊 | 突然出现全新的信息 |
| 多方各知一部分 | 拼图感 | 不同视角拼出完整真相 |

## 四、节奏控制

### 全书节奏公式

```
低谷受压 → 小反击 → 小胜利 → 新危机 → 升级逆袭 → 大高潮 → 反转收官
```

### 爽点密度

| 类型 | 频率 |
|------|------|
| 网文（玄幻/都市） | 每3-5章一小爽，每10章一大爽 |
| 言情 | 每10章一次感情升温 |
| 悬疑 | 每5章一个谜题进展 |

### 张弛有度原则

- 3段爽点配1段铺垫
- 紧张后轻松
- 感情爆发后缓冲
- 大战前宁静

### 10章情绪周期单元

| 章节范围 | 情绪走向 | 核心任务 |
|---------|---------|---------|
| 第1-3章 | 冲突爆发 | 引入矛盾，制造紧迫感 |
| 第4-6章 | 压力升级 | 对手施压，主角陷入困境 |
| 第7-9章 | 反转铺垫 | 积蓄力量，准备反击 |
| 第10章 | 爽点爆发 + 留钩子 | 释放情绪，为下一周期铺垫 |

## 五、伏笔管理

### 伏笔四原则

1. 所有伏笔必有回收
2. 不是所有伏笔都要在高潮回收
3. 伏笔要自然（第一次出现时不能太刻意）
4. 大伏笔小伏笔搭配（3-5个大伏笔贯穿全书）

### 伏笔埋设技巧

| 技巧 | 描述 |
|------|------|
| 闲笔带过 | 在不重要的场景中顺带提及 |
| 人物随口一提 | 角色聊天时无意中说到 |
| 反复出现的意象 | 同一个物品/场景多次出现 |
| 闪回片段 | 突然插入一段过去的记忆 |

## 六、高潮设计

### 终极高潮公式

```
核心冲突解决 + 情感弧光完成 + 伏笔回收 + 金句点题
```

### 高潮节奏

```
铺垫（蓄势）→ 触发（点燃）→ 爆发（最燃）→ 反转（意想不到）→ 余韵（回味）
```

## 七、大纲方法

### 九种大纲写法（选择适合自己的）

| 方法 | 适用场景 | 难度 |
|------|---------|------|
| 线性大纲法（三幕式） | 新手最推荐 | ★ |
| 雪花法（十步迭代） | 从一句话扩展 | ★★ |
| 分卷大纲法 | 连载网文 | ★★ |
| 卡片式大纲 | 单元剧/副本流 | ★★ |
| 混合型双螺旋 | 商业写作推荐 | ★★★ |
| 人物驱动型 | 文学性较强 | ★★★ |
| 情节驱动型 | 商业类型小说 | ★★ |
| 主题驱动型 | 围绕明确主题 | ★★★ |
| 世界架构驱动 | 奇幻/科幻 | ★★★ |

### 一页纸大纲模板

```markdown
# {书名} 一页纸大纲

- 类型：
- 目标读者：
- 一句话卖点：
- 主角三要素（欲望/缺陷/底牌）：
- 核心冲突：
- 三幕骨架：
  - 第一幕（开篇）：
  - 第二幕（发展）：
  - 第三幕（结局）：
- 关键转折点：
- 结局：
- 伏笔清单：
```

### 世界观构建四原则

1. **够用就好** — 只写和故事相关的部分
2. **循序渐进** — 融入剧情展现，不要一次性倾倒
3. **逻辑自洽** — 准备设定本随时翻看
4. **贴近现实** — 即使玄幻也要有现实影子

## 八、卡文急救五招

1. **回顾大纲** — 拉回主线
2. **制造意外** — 新敌人/新盟友/新信息/新环境
3. **切视角** — 换到另一个角色的视角
4. **换环境** — 让角色去一个新的地方
5. **跳写** — 跳过卡住的部分，先写后面的
