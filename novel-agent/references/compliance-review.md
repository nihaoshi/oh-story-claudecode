# 合规审查详细流程

> 三重质量保障的最后一重。检查执行度：章纲是否被执行了？设定是否被遵守了？人设是否被维护了？

---

## 一、五大审查维度

### 维度1：情节合规

**检查内容**：本章剧情是否符合大纲规划

| 检查项 | 具体方法 |
|--------|---------|
| 核心事件是否完成 | 对比章纲，本章的核心事件是否都写到了 |
| 剧情方向是否偏离 | 是否出现了章纲中没有的关键转折 |
| 章节目标是否达成 | 本章应该达成的剧情目标是否实现 |
| 衔接是否自然 | 与上一章的衔接是否流畅 |
| 字数是否合理 | 是否在目标字数范围内（偏差不超过30%） |

### 维度2：设定合规

**检查内容**：世界观/力量体系是否一致

| 检查项 | 具体方法 |
|--------|---------|
| 力量体系一致 | 等级、能力、代价是否与设定文档一致 |
| 世界观规则一致 | 地理、时间、社会规则是否与设定文档一致 |
| 新设定引入 | 如果引入了新设定，是否合理且已记录 |
| 物品属性一致 | 之前描述过的物品是否有矛盾的变化 |

### 维度3：人物合规

**检查内容**：人设是否崩塌、OOC

| 检查项 | 具体方法 |
|--------|---------|
| 性格一致 | 角色行为是否符合人物谱中的性格描述 |
| 能力一致 | 角色展现的能力是否在当前境界范围内 |
| 动机一致 | 角色的选择是否有合理的动机支撑 |
| 关系一致 | 角色间的关系是否与人物关系状态一致 |
| 对话一致 | 说话风格是否符合语言习惯速查卡 |
| 成长合理 | 角色的变化是否有足够的驱动力 |

### 维度4：伏笔合规

**检查内容**：伏笔是否按计划管理

| 检查项 | 具体方法 |
|--------|---------|
| 计划埋设 | 本章计划埋设的伏笔是否都埋了 |
| 计划回收 | 本章计划回收的伏笔是否都回收了 |
| 回收质量 | 回收方式是否自然、不突兀 |
| 新伏笔记录 | 意外产生的新伏笔是否已记录到伏笔追踪 |
| 紧迫伏笔 | 🔴紧迫伏笔是否在计划内处理 |
| 伏笔一致性 | 新埋设的伏笔是否与已有伏笔冲突 |

### 维度5：认知合规

**检查内容**：认知遮蔽是否严格执行

| 检查项 | 具体方法 |
|--------|---------|
| 角色信息边界 | 每个角色知道/不知道的信息是否正确 |
| 读者信息边界 | 读者视角是否泄露了角色视角不该有的信息 |
| 伏笔揭示时机 | 伏笔的揭示是否在认知解封之后 |
| 推理合理性 | 角色的推理/猜测是否有足够的信息基础 |

---

## 二、审查强度分级

### 快速审查（日常过渡章）

仅检查：
- 情节合规：核心事件是否完成 ✅/❌
- 人设合规：主要角色是否OOC ✅/❌
- 认知合规：信息边界是否越界 ✅/❌

预计时间：简短

### 完整审查（关键剧情章）

五个维度全部检查，每项列出具体结果。

预计时间：中等

### 完整+认知专项（真相揭露章/转折章）

五个维度全部检查 + 认知遮蔽专项深度审查：
- 详细追踪每个角色在本章的信息获取路径
- 检查读者视角与角色视角的信息差是否合理
- 确认认知解封的时机和方式

预计时间：较长

### 审查强度判断标准

| 章节类型 | 审查强度 |
|---------|---------|
| 日常对话/过渡 | 快速审查 |
| 事件推进/冲突升级 | 完整审查 |
| 高潮/转折/真相揭露 | 完整+认知专项 |
| 新角色出场 | 完整审查+兼容性检查 |
| 新设定引入 | 完整审查+设定合规专项 |

## 四、常见问题及修复方向

| 问题类型 | 常见原因 | 修复方向 |
|---------|---------|---------|
| 人设崩塌 | AI忘了角色性格 | 重新读取人物谱，重写相关段落 |
| 设定矛盾 | AI编造了不存在的设定 | 对照设定文档，删除或修正 |
| 认知越界 | 角色知道了不该知道的 | 改为猜测/推断，或删除相关信息 |
| 伏笔遗漏 | AI忘了要埋的伏笔 | 补充伏笔，或调整到下一章 |
| 剧情偏离 | AI自由发挥偏离了大纲 | 回到章纲，重写偏离的部分 |
| 节奏失控 | 关键事件提前/延后触发 | 调整事件顺序或拆分/合并章节 |
