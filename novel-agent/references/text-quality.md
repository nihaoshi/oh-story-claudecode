# 文本质感优化详细流程

> 解决AI写作最大的问题：AI味。通过系统化的四步检测，将文本从"能读"提升到"好读"。

---

## 一、核心原则

- **够好就行**：60分→75分，不追求100分完美
- **前10章重点打磨**：建立全书的文风基准线
- **后续章节参照基准**：保持一致性比追求完美更重要

---

## 二、四步检测流程

### Step 1：复读现象检测

**问题描述**：同一词汇、句式、结构在短距离内重复出现。

**检测方法**：
- 扫描全文，找出连续出现3次以上的词汇
- 找出结构高度相似的相邻句子
- 找出反复使用的过渡词

**常见复读模式**：

| 复读类型 | 示例 | 修复方法 |
|---------|------|---------|
| 动词复读 | "他走过去...他走回来...他走到门口..." | 替换动词：踱/迈/转身/跨步 |
| 句式复读 | "他看了看X。他想了想Y。他听了听Z。" | 变换句式：长短交替、主被动切换 |
| 过渡词复读 | "突然...突然...突然..." | 减少使用，用动作/场景自然过渡 |
| 形容词复读 | "美丽的...美丽的...美丽的..." | 具体化：用细节替代抽象形容 |
| 段首复读 | 每段都以"他"开头 | 变换段首：环境/动作/对话/心理交替 |

**修复优先级**：P0（必须修复）

---

### Step 2：AI味空洞检测

**问题描述**：大段文字看似优美但没有实质内容，典型的AI腔调。

**常见AI味模式**：

| 模式 | 示例 | 修复方法 |
|------|------|---------|
| 空洞抒情 | "他感到一种前所未有的复杂情绪涌上心头..." | 用具体行为替代：攥紧拳头/深吸一口气/转过身 |
| 排比堆砌 | "他想起了过去，想起了未来，想起了那些..." | 精简到1-2个具体意象 |
| 万能形容 | "一种奇异的感觉/一股莫名的力量..." | 具体化：什么感觉？什么力量？ |
| 假大空 | "在这个广袤的世界中，一切都是那么的..." | 删掉，直接写具体的场景/动作 |
| 解释性旁白 | "他知道，从这一刻起，一切都将改变。" | 删掉或改为行为展示 |
| 情感标签 | "他感到悲伤/愤怒/兴奋..." | 用行为和环境让读者自己感受 |

**检测提示模板**：
```
请逐段检查以下文本，找出所有"AI味空洞"：
1. 有形容无实质的段落
2. 排比堆砌
3. 解释性旁白（告诉读者应该感受什么）
4. 情感标签（直接写出情感名称）
5. 过度修饰的段落

标记每个问题并给出修复建议。
```

**修复优先级**：P0（必须修复）

---

### Step 3：风格漂移检测

**问题描述**：文本偏离了预设的风格指南/风格样本。

**检测方法**：
1. 重新读取 `叙述风格样本.md`
2. 对比当前章节的语调、句式、用词是否与样本一致
3. 检查是否混入了其他风格

**常见漂移**：

| 漂移类型 | 表现 | 修复方法 |
|---------|------|---------|
| 语调漂移 | 轻松的故事突然变得沉重 | 调整用词和句式 |
| 时代漂移 | 古代故事突然出现现代用语 | 替换为时代合适的词汇 |
| 人称漂移 | 第三人称偶尔切到第一人称 | 统一人称 |
| 视角漂移 | 有限视角突然写了主角不知道的事 | 删除或改为猜测/推测 |
| 详细度漂移 | 某些段落描写过细/过粗 | 参照基准调整 |

**修复优先级**：P1（建议修复）

---

### Step 4：文本生硬检测

**问题描述**：段落间过渡生硬、对话与叙述割裂、场景转换突兀。

**检测方法**：
- 检查段落间的逻辑连接
- 检查对话与叙述的交替是否自然
- 检查场景转换是否有过渡
- 检查时间跳跃是否有交代

**常见生硬模式**：

| 模式 | 示例 | 修复方法 |
|------|------|---------|
| 对话-叙述割裂 | 对话后直接跳到大段环境描写 | 在对话和描写之间加过渡动作 |
| 场景突转 | 上一段在室内，下一段直接在街上 | 加过渡句或分隔符 |
| 时间跳跃 | 没有交代就跳过了一天 | 加时间交代词 |
| 因果缺失 | A事件后直接跳到C事件，缺B | 补充因果链 |
| 情绪断裂 | 上一段愤怒，下一段平静 | 补充情绪过渡 |

**修复优先级**：P1（建议修复）

---

## 三、修改优先级体系

| 优先级 | 类型 | 说明 | 是否必须修改 |
|--------|------|------|-------------|
| P0 | 复读现象、AI味空洞 | 严重影响阅读体验 | ✅ 必须 |
| P1 | 风格漂移、文本生硬 | 明显影响质感 | 建议修改 |
| P2 | 个别用词不佳、句式单调 | 锦上添花 | 可选 |
| P3 | 文学性提升、修辞优化 | 完美主义 | 可选 |

## 四、人机协作润色分工

| 任务 | AI擅长 | 需要人工 |
|------|--------|---------|
| 复读检测 | ✅ 全文扫描找重复 | 判断哪些需要修改 |
| AI味检测 | ✅ 识别典型AI腔 | 判断修改方向是否合适 |
| 风格一致性 | ✅ 对比基准样本 | 判断风格是否符合预期 |
| 过渡修复 | ✅ 识别断裂点 | 判断过渡是否自然 |
| 用词优化 | ✅ 提供替换建议 | 选择最合适的替换 |
| 整体节奏 | 部分 | ✅ 人类对节奏的感觉更准 |

## 五、必删词完整列表

### 高频删除词（出现即删）

不由得、不禁、宛如、恍若、似是而非、犹如、恍如、仿佛、凝视着、凝望、倒映着、诉说着、映照着

### 必改表达及替换方案

| 原表达 | 替换方案 |
|--------|---------|
| 嘴角微微上扬 | 笑了笑/咧嘴/嘴角动了动 |
| 眼中闪过一丝X | 眼神变了/目光一沉/眼里有了X |
| 心中暗想 | 直接删，改为动作 |
| 一股暖流涌上心头 | 鼻子一酸/手攥紧了 |
| 仿佛整个世界都X | 删掉夸张 |
| 视线模糊了 | 眼眶热了/眼睛酸了 |
| 声音颤抖着说 | 用动作打断 |
| 深深地X了 | X了X（删"深深地"） |
| 默默地X | 直接X |
| 轻轻地X | 直接X |
| 缓缓地X | 直接X |

### 必改句式

| 原句式 | 替换方案 |
|--------|---------|
| 他感到一阵X涌上心头 | 删掉感受句，加动作句 |
| 她的X仿佛/宛如Y | 删比喻或换新奇比喻 |
| 这不仅X，更Y | 删掉"不仅"那半句 |
| X的同时，Y | 断开成两句 |
| 这一刻，X | 删"这一刻" |
| 他知道X，但Y | 直接写Y |
| 尽管X，然而Y | 直接写Y |
| 面对X，他选择了Y | 删铺垫 |

### 量化标准

每千字禁止词/套话词计数：
- 0-2个 = 基本无AI味 ✅
- 3-5个 = 轻微AI味（建议修改）
- 6-10个 = 明显AI味（必须修改）❌
- 10+个 = 典型AI文（重写）❌❌

## 六、其他检测方法

### 遮名法
遮住角色名字，看能不能分辨谁在说话。能分辨 = 对话写得好。

### 朗读法
- 读着拗口 = 结构有问题
- 读着平淡 = 缺动作细节
- 读着矫情 = 比喻心理太多
- 读着顺畅但没感觉 = 缺留白

### 24小时冷读法
隔一天再读。如果产生"这真的是我写的吗"的尴尬感 = AI味还在。

## 七、前10章基准线建立

前10章需要额外关注：

1. **确定叙述人称和视角** — 全文统一
2. **确定语言风格** — 古风/现代/混合
3. **确定描写密度** — 每章环境描写的篇幅比例
4. **确定对话密度** — 对话与叙述的比例
5. **确定节奏模板** — 每章的情绪起伏模式
6. **建立角色语言** — 每个角色的说话风格

**前10章完成后**：
- 从中摘取典型段落 → 写入 `叙述风格样本.md`
- 总结风格规则 → 更新 `CLAUDE.md` 中的风格指南
- 后续章节以此为基准
