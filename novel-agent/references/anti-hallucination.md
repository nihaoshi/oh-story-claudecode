# 防幻觉详细操作流程

> AI写作中最常见的问题：编造不存在的设定、人设崩塌、前后矛盾。本流程提供系统化的防御机制。

---

## 一、核心机制：三层防线

```
第一层：精纲改造（写作前）
  ↓
第二层：写作约束注入（写作中）
  ↓
第三重：章节校验（写作后）
```

---

## 二、第一层：精纲改造

### 2.1 将开放性描述改为边界明确的指令

**改造前（开放性）**：
> 主角在山洞中发现了一本古老的功法，开始修炼。

**改造后（边界明确）**：
> 主角在【青云山·第三洞窟】中发现一本【玄级中品功法·五行遁法】。
> 注意：① 此功法已在修炼体系.md中登记为"玄级中品" ② 不能出现其他未登记的功法名称 ③ 修炼过程不超过本章30%篇幅

### 2.2 设定清单化

在精纲中列出本章**涉及的所有设定条目**：

```
【本章设定清单】
- 青云山：已在世界设定中登记，海拔3000米，灵气浓度中等
- 五行遁法：已在修炼体系中登记，玄级中品，需要金木水火土五行灵根
- 主角当前境界：炼气期第七层（故事状态.md中记录）
- 禁止出现的设定：[列出本章不应该出现的设定]
```

### 2.3 因果链明确

每个事件的因果关系必须明确：

```
事件1：主角进入山洞
  因：上一章结尾主角决定探索
  果：发现五行遁法
  前提：主角当时在青云山附近（故事状态.md确认）

事件2：主角开始修炼
  因：发现了五行遁法
  果：突破到炼气期第八层
  前提：主角有五行灵根（人物谱确认）
  注意：不能在本章就突破到筑基期（节奏太快）
```

---

## 三、第二层：写作约束注入

### 3.1 在写作指令中注入约束

```
⚠️ 写作约束：
1. 本章只能使用设定清单中列出的设定条目
2. 新出现的任何名词/能力/地名必须先在设定中登记
3. 主角的认知范围严格遵守认知遮蔽表
4. 不能出现以下内容：[根据精纲列出的禁止事项]
5. 人物对话风格必须符合语言习惯速查卡
```

### 3.2 认知遮蔽注入

```
⚠️ 认知遮蔽约束（第X章）：
- 主角知道：[从认知遮蔽表读取]
- 主角不知道：[从认知遮蔽表读取]
- 配角A知道：[从认知遮蔽表读取]
- 配角A不知道：[从认知遮蔽表读取]
- 读者知道但角色不知道的信息：[标注，写作时不能通过角色行为泄露]
```

---

## 四、第三层：章节校验

### 4.1 六大检查维度

#### 维度1：禁用词检查

扫描全文，检查是否使用了本章不该出现的词汇：
- 该时代不该有的现代词汇（历史类）
- 该世界观不该有的术语（玄幻/科幻类）
- 前文已经废弃的旧称呼
- 设定中不存在的能力/物品名称

#### 维度2：人物行为检查

逐个检查本章出场人物：
- 行为是否符合人设（性格、能力、背景）
- 是否出现了超出其能力范围的行为
- 是否表现出了超出其认知范围的信息
- 对话风格是否符合语言习惯速查卡

#### 维度3：剧情边界检查

- 是否偏离了章纲/精纲的核心事件
- 是否出现了章纲中没有的关键剧情
- 章节长度是否在合理范围内
- 节奏是否与计划一致

#### 维度4：伏笔执行检查

- 本章应该埋设的伏笔是否都埋了
- 本章应该回收的伏笔是否都回收了
- 回收方式是否合理（不突兀）
- 有没有意外引入新的伏笔（需要记录）

#### 维度5：认知遮蔽检查

- 各角色的信息获取是否合理
- 有没有角色知道了不该知道的信息
- 伏笔揭示是否在认知解封之后
- 读者视角是否泄露了角色视角不该有的信息

#### 维度6：设定一致性检查

- 力量体系是否一致（等级、能力、代价）
- 世界观规则是否一致（地理、时间、社会规则）
- 物品属性是否一致（之前描述过的物品没有变化）
- 时间线是否合理（没有时间倒退或不合理的跳跃）

### 4.2 常见幻觉类型速查表

| 幻觉类型 | 表现 | 防御方法 |
|---------|------|---------|
| 设定编造 | 凭空创造不存在的设定 | 设定清单+禁用词检查 |
| 人设崩塌 | 角色行为不符合人设 | 人设校验+认知遮蔽检查 |
| 时间矛盾 | 时间线出现跳跃或倒退 | 时间线校验 |
| 空间矛盾 | 角色位置不合理 | 位置追踪检查 |
| 能力膨胀 | 角色突然变强没有铺垫 | 境界/能力校验 |
| 信息泄露 | 角色知道了不该知道的 | 认知遮蔽检查 |
| 重复描写 | 与前文重复的场景/事件 | 前文对照检查 |
| 名词混乱 | 同一事物用了不同名称 | 用语统一表检查 |

### 4.3 输出校验报告

```markdown
# 防幻觉校验报告（第X章）

## 校验结果
- 禁用词检查：✅/❌
- 人物行为检查：✅/❌
- 剧情边界检查：✅/❌
- 伏笔执行检查：✅/❌
- 认知遮蔽检查：✅/❌
- 设定一致性检查：✅/❌

## 发现的问题
- [如有问题，列出具体问题和修改建议]

## 总结
通过/未通过 → [简要说明]
```

## 五、分阶段校验策略

| 创作阶段 | 校验强度 | 原因 |
|---------|---------|------|
| 第1-10章 | 每章完整校验 | 建立基准线，确保所有设定正确引入 |
| 第11-30章 | 每5章一次完整校验，中间快速校验 | 基准线已建立，重点检查变化 |
| 第31章起 | 仅关键章节完整校验 | 体系已稳定，只检查转折/高潮/新设定引入 |

**快速校验**：只检查维度1（禁用词）+ 维度5（认知遮蔽）+ 维度6（设定一致性）
**完整校验**：六个维度全部检查
