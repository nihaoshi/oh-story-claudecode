# novel-agent 技能使用说明

> 本文档说明 novel-agent 技能的完整使用方法、各组件的关系、以及不同场景下的工作流程。

---

## 一、组件架构

```
┌─────────────────────────────────────────────────┐
│                novel-agent 技能                   │
│  SKILL.md（主文件）+ 10个 reference 文件           │
│  作用：提供完整的方法论（Phase 1-13）              │
│  加载方式：/novel-agent 调用时加载                │
└───────────────────┬─────────────────────────────┘
                    │ 方法论
                    ▼
┌─────────────────────────────────────────────────┐
│              novel-writer 自定义 Agent            │
│  {项目}/.claude/agents/novel-writer.md           │
│  作用：执行者，内联了核心创作规则                  │
│  加载方式：项目默认 agent，每次会话自动加载         │
└───────────────────┬─────────────────────────────┘
                    │ 规则 + 项目配置
                    ▼
┌─────────────────────────────────────────────────┐
│                 CLAUDE.md                         │
│  作用：项目档案（书名、人物、大纲、风格指南）       │
│  加载方式：每次会话自动加载（始终在上下文中）       │
└───────────────────┬─────────────────────────────┘
                    │ 设定数据
                    ▼
┌─────────────────────────────────────────────────┐
│              00-设定/ 目录                         │
│  人物谱、伏笔追踪、认知遮蔽表、故事状态等          │
│  作用：项目的具体数据（人物、剧情、进度）           │
│  加载方式：按需读取（写章节时读相关文件）           │
└─────────────────────────────────────────────────┘
```

**一句话总结**：
- **技能** = 方法论（怎么写）
- **Agent** = 执行者（带着规则干活）
- **CLAUDE.md** = 项目档案（写什么）
- **设定文件** = 数据（人物、剧情、进度）

## 二、各组件详细说明

### 2.1 novel-agent 技能（SKILL.md + references/）

**位置**：`~/.claude/skills/novel-agent/`

**包含**：
| 文件 | 内容 |
|------|------|
| SKILL.md | 主文件，Phase 1-13 完整流程 + 内联的 reference 精华 |
| references/agent-persona.md | 作者人格定义 |
| references/anti-hallucination.md | 防幻觉详细流程 |
| references/text-quality.md | 文本质感优化+去AI味 |
| references/compliance-review.md | 合规审查流程 |
| references/context-continuity.md | 上下文连贯管理 |
| references/character-craft.md | 人物塑造深度技巧 |
| references/plot-design.md | 情节设计方法论 |
| references/type-styles.md | 七种类型风格写法 |
| references/long-novel-management.md | 长篇管理策略 |
| references/worldbuilding.md | 世界观构建方法论 |

**何时使用**：
- 新建项目时（Phase 1-4）
- 需要深度参考时（读对应 reference）
- 日常写章节时不需要读——agent 已内联核心规则

### 2.2 novel-writer 自定义 Agent

**位置**：`{项目目录}/.claude/agents/novel-writer.md`

**包含**：必读文件清单 + 核心创作规则 + 全链路流程 + Phase 9 强制清单 + 校验节奏 + 长篇策略

**何时使用**：写章节、修改章节、一致性检查时（每次会话自动加载）

### 2.3 CLAUDE.md

**位置**：`{项目目录}/CLAUDE.md`

**包含**：项目概况 + 技能配置表 + 风格指南 + 创作规则 + 设定文件索引 + 更新检查清单

**何时使用**：每次会话自动加载

### 2.4 设定文件

**位置**：`{项目目录}/00-设定/`

**何时读取**：写章节前读相关文件，写完后更新

## 三、不同场景的工作流程

### 新建小说项目
```
/novel-agent 新建项目 {书名}
→ /novel-agent 世界观构建
→ /novel-agent 生成大纲
→ /novel-agent 生成人设
→ /novel-agent 拆解章纲
→ /novel-agent 拆解精纲
```

### 写一个新章节
```
/novel-agent 写章节
→ Phase 5→6→7→8→9→10 全链路
```

### 修改章节
```
/novel-agent 修改 第X章 {要求}
→ Phase 7→8→9→10
```

### 一致性/节奏检查
```
/novel-agent 一致性检查    → Phase 10
/novel-agent 节奏检查      → Phase 11
```

## 五、换小说不需要重建 Agent

Agent 里的规则是通用的。换小说只需：
1. 新建项目目录
2. 新建 CLAUDE.md
3. 新建设定文件
4. 复制 novel-writer agent 到新项目的 `.claude/agents/` 下

---

## 六、常见问题

**Q: 技能和 Agent 什么关系？**
A: 技能是方法论手册，Agent 是执行者。写章节用 Agent，新建项目用技能。

**Q: reference 文件还有用吗？**
A: 有，深度参考时读取。核心规则已内联到 Agent 和 CLAUDE.md。

**Q: 字数不达标？**
A: 必须扩写。用 PowerShell 计数，<2500 必须补。
