**简单记法**：R4（作者人格）+ R9（类型风格）每次写章必读。其余按阶段读。

### R1：世界观构建（worldbuilding.md）

**八条法则**：
1. 设定先行逻辑闭环 — 先构建底层规则，再推导故事
2. 力量有界代价机制 — 一切能力有限制和代价
3. 二元对立动态平衡 — 相互矛盾的力量体系
4. 具象命名清晰量化 — 能力名称具体，等级可量化
5. 多线叙事宏观微观切换
6. 古今结合理性思辨
7. 伏笔埋设首尾呼应
8. 爽点密集节奏张弛

**历史类型**：朝代背景+真实事件+社会结构

### R2：情节设计（plot-design.md）

**冲突公式**：想要 → 得不到 → 有人拦 → 只能拼 → 付出代价

**四种钩子**：突然出现的人 / 突然反转的真相 / 突然到来的危机 / 一句震惊的话

**钩子频率**：章中每500-800字一个小悬念，章尾留钩子

**伏笔四原则**：必有回收 / 不都在高潮 / 要自然 / 大小搭配

**爽点密度**：网文每3-5章一小爽，每10章一大爽

**10章情绪周期**：冲突爆发(1-3) → 压力升级(4-6) → 反转铺垫(7-9) → 爽点爆发(10)

### R3：人物塑造（character-craft.md）

**三秒法则**：角色第一次出场 — 一个动作 + 一个眼神 + 一个说话方式

**反应链**（性格=反应方式）：
| 场景 | 检测 |
|------|------|
| 危险 | 冲/退/观察 |
| 争吵 | 硬刚/回避/讲理 |
| 诱惑 | 坚守/动摇/先犹豫后拒绝 |
| 背叛 | 报复/原谅/表面原谅内心记仇 |

**弱点三件套**：情绪弱点 + 智力盲区 + 现实限制

**对话四点**：口头禅 + 长度 + 表达方式 + 讨厌的词

**对话五层**：传递信息 → 展现性格 → 推动冲突 → 潜台词 → 留白

**遮名测试**：遮住名字能分辨谁在说话 = 对话写得好

### R4：作者人格（agent-persona.md）

**铁律**：读者体验第一 / 逻辑自洽 / 人设不崩 / 伏笔回收 / 信息差 / 不解释太多

**节奏指标**：
- 3000字内必有小高潮
- 万字内必有大转折
- 压抑不超过连续2章
- 纯对话不超过连续3段
- 纯叙述不超过连续500字

**历史类型**：考据到位 / 文言白话之间 / 不写公元纪年 / 器物准确 / 白描为主

### R5：文本质感（text-quality.md）

**四步检测**：复读现象 → AI味空洞 → 风格漂移 → 文本生硬

**AI味速查**：
| 模式 | 修复 |
|------|------|
| 空洞抒情 | 用具体行为替代 |
| 排比堆砌 | 精简到1-2个意象 |
| 情感标签 | 用行为和环境让读者自己感受 |
| 解释性旁白 | 删掉或改为行为展示 |

**检测法**：遮名法（分辨谁在说话）/ 朗读法（拗口=结构问题）

**量化**：每千字禁止词 0-2个=✅ / 3-5=改 / 6+=重写

### R6：防幻觉（anti-hallucination.md）

**三层防线**：精纲改造（写作前）→ 写作约束注入（写作中）→ 章节校验（写作后）

**六大维度**：禁用词 / 人物行为 / 剧情边界 / 伏笔执行 / 认知遮蔽 / 设定一致

**幻觉速查**：设定编造→清单检查 / 人设崩塌→认知检查 / 信息泄露→遮蔽检查

### R7：合规审查（compliance-review.md）

**五维度**：情节合规 / 设定合规 / 人物合规 / 伏笔合规 / 认知合规

**审查强度**：日常→快速 / 事件推进→完整 / 高潮转折→完整+认知专项

### R8：上下文连贯（context-continuity.md）

**追踪文件=记忆**：章节摘要 / 伏笔状态 / 人物关系 / 写作工作态

**伏笔状态**：🟢远期 / 🟡待处理 / 🔴紧迫 / ⚠️断线 / ✅已回收 / ❌废弃

**断线预警**：🟢→🟡(计划前5章) / 🟡→🔴(计划前2章) / 🔴→⚠️(超期)

### R9：类型风格（type-styles.md）

**历史类型**：
- 考据到位（服饰/礼仪/官制/称呼/饮食）
- 文言与白话之间
- 不写公元纪年，不出现现代词汇
- 器物名称准确
- 白描为主，统一语感

**去AI味重点**：统一语感、删华丽骈文、白描为主

### R10：长篇管理（long-novel-management.md）

**百万字三幕式**：第一幕(1-50章)铺垫 / 第二幕(50-300章)推进 / 第三幕(300+章)收线

**10章周期**：冲突爆发(1-3) → 压力升级(4-6) → 反转铺垫(7-9) → 爽点爆发(10)

**避免烂尾**：提前50章收束 / 设计终极高潮 / 最后10章收线 / 尾声写法

**卡文急救**：回顾大纲 / 制造意外 / 切视角 / 换环境 / 跳写

## 通用风格铁律（每章必用）

1. 长短句交错，避免连续排比
2. 对话口语化、个性鲜明，不借对话交代背景
3. 克制修饰词（仿佛/宛如/犹如/如同/好像）
4. 细节融入动作，不单独堆砌环境描写
5. 情感不说破，用行为和场景传递
6. 不完美句式，适当断句
7. 避免完美弧线，可戛然而止
8. 具体大于抽象
9. 少用成语
10. 白描为主

### 禁止词（出现即删）

不由得、不禁、宛如、恍若、犹如、恍如、仿佛、凝视着、凝望、倒映着、诉说着、映照着、嘴角微微上扬、眼中闪过一丝、心中暗想、一股暖流、不禁感叹、深深地、默默地、轻轻地、缓缓地

### 字数要求

每章2500-5000字。用PowerShell计数：
```powershell
$content = Get-Content '文件路径' -Raw -Encoding UTF8; ($content -replace '[\s\r\n]','').Length
```
